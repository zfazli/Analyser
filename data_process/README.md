### Training Data Analysis

This section is dedicated to analyzing the data used for model training.

The precomputed results are available in the `process_result` directory.
Since the file size was too large, it has been uploaded to [LINK]. Please download it and extract it into the process_result directory.

To process your own dataset, first run `run_parser.py`, followed by `run_feature_extraction.py`.

Figures 1, 2, and 3 in the paper were generated using the `generate_figures_1_2.ipynb` notebook.

Additionally, the `sampler` module was used to select the samples excluded from different analyses. The results of the sample selection process are available in the `filters` directory.
